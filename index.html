24-Point Game with A=1 (合24游戏)

Combine the 4 numbers using +, -, ×, ÷ to make 24

Start building your expression...

How to play:

  • Use each of the four numbers exactly once (A=1 if enabled)
  • Combine them using +, -, ×, ÷ operations
  • You can use parentheses to change the operation order
  • The final result must equal exactly 24
  • When A is included, you can use either the number 1 or A in your expression
